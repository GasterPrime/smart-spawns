# Smart Spawns

Server-side spawn rules for [Cobblemon](https://modrinth.com/mod/cobblemon).

> Work in progress. Not released yet.

## Planned features

- Keep fully evolved Pokémon out of wild spawns, worked out from Cobblemon's own evolution data so new species and addons are covered automatically
- Optional rule: block evolved Pokémon that spawn below their evolution level
- Per-world rules and an exception list
- Stop the same species from spawning in tight clusters
- English config file and a reload command

Players do not need to install anything. Install it on the server only.

## Requirements

| | Version |
|---|---|
| Minecraft | 1.21.1 |
| Fabric Loader | 0.17.2 or newer |
| Fabric API | any 1.21.1 build |
| Cobblemon | 1.8.0 or newer |

Fabric Language Kotlin is already bundled inside Cobblemon.
